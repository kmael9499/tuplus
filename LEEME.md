# Abrir esta versión

1. Extrae el ZIP completo.
2. Abre la carpeta **TUPLUS-CORREGIDO-V2** en VS Code.
3. Abre **index.html** con Live Server: es la página principal, con las cinco tarjetas y el carrusel recuperados.
4. Pulsa **Cotizar mi web** para abrir **cotizador.html**, en otra página.

El cotizador empieza en Perú y soles. Elige otro país para cambiar su moneda automáticamente.

Utiliza esta carpeta completa. Copiar solo index.html a la carpeta antigua deja estilos y funciones sin actualizar. Al iniciar Live Server, comprueba que abriste el index.html de esta carpeta.

README.md indica dónde modificar las tarifas, WhatsApp y la conexión opcional a MySQL. No hace falta una base de datos para elegir países, calcular, descargar el resumen o preparar WhatsApp.
